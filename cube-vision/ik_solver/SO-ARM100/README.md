# SO-ARM100 (simulation subset)

This directory contains a small subset of
[TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100) —
only the `Simulation/SO101` URDF and meshes, which the diagnostic tooling in
`cube-vision` uses for forward-kinematics checks.

For the full CAD (STEP/STL), print files, and assembly documentation, use the
upstream repository. The original license is preserved in `LICENSE`.
